# Proyecto de Pruebas de Software

## Criterios

### Documentacion
*Este criterio depende de una competencia de aprendizaje Documentacion*

La documentacion del proyecto debe contener:
- Descripcion
- Requerimientos
- Herramientas utilizadas
- Dependencias
- Como correr la aplicacion
- Como contribuir
- Estructura general de archivos
- Mockups / imagenes de las distintas vistas de la aplicacion

**Calificaciones:**
- **5 pts** - Con marcas
- **0 pts** - Sin marcas

**Pts:** 5 pts

---

### Revisiones de codigo
*Este criterio depende de una competencia de aprendizaje Revisiones de codigo*

Deben existir pull requests con revisiones de codigo aprobadas y acciones de GitHub exitosas como parte del proceso de desarrollo del proyecto.

**Calificaciones:**
- **3 pts** - Con marcas
- **0 pts** - Sin marcas

**Pts:** 3 pts

---

### Analisis estatico
*Este criterio depende de una competencia de aprendizaje Analisis estatico*

El repositorio debe tener al menos un linter configurado, y una accion de GitHub que lo ejecute en cada pull request.

**Calificaciones:**
- **4 pts** - Con marcas
- **0 pts** - Sin marcas

**Pts:** 4 pts

---

### Pruebas unitarias y de integracion
*Este criterio depende de una competencia de aprendizaje Pruebas unitarias y de integracion*

Deben existir pruebas unitarias y de integracion para las diferentes funciones y clases de la aplicacion. Estas pruebas deben ser ejecutadas en cada pull requests como parte de un workflow.

**Calificaciones:**
- **5 pts** - Con marcas
- **0 pts** - Sin marcas

**Pts:** 5 pts

---

### Cobertura de codigo
*Este criterio depende de una competencia de aprendizaje Cobertura de codigo*

El proyecto debe tener una accion de GitHub que revise la cobertura de codigo y falle si las metricas disminuyen.

**Calificaciones:**
- **3 pts** - Con marcas
- **0 pts** - Sin marcas

**Pts:** 3 pts

---

### Pruebas de sistema
*Este criterio depende de una competencia de aprendizaje Pruebas de sistema*

Se deben agregar pruebas de sistema utilizando BDD y Selenium (o cualquier otra herramienta similar).

**Calificaciones:**
- **5 pts** - Con marcas
- **0 pts** - Sin marcas

**Pts:** 5 pts

---

### Presentacion
*Este criterio depende de una competencia de aprendizaje Presentacion*

Todos los miembros del equipo deben presentar el proyecto y las distintas pruebas existentes.

**Calificaciones:**
- **5 pts** - Con marcas
- **0 pts** - Sin marcas

**Pts:** 5 pts
